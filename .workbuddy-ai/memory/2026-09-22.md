## 全量测试抓到两条问题（说明「跳过全量」的代价）

- **过期断言**（真失败）：`tests/test_export.py::test_wheel_scrolls_exactly_twice_the_system_default`
  把倍数**写死成 2.0**，滚轮改成 6 倍后必然失败（实测 5.975）。改法：断言直接取
  `app_main.EDITOR_WHEEL_FACTOR`，并改名 `test_wheel_scrolls_exactly_the_configured_factor`。
  **教训：常量型断言别写死数字。**
- **偶发失败**（`test_performance` 抛 `StopIteration`）：`test_wrapped_quote_gets_continuation_lines`
  时好时坏，单独跑 3 次全过。根因是 `_visible_lines()` 按 `editor.winfo_height()` 算可见范围
  （`max(1, height)`），**窗口刚映射时高度可能还是 1** → 只看得到第 1 行 → 第 4 行找不到。
  全量跑时负载高、窗口映射慢就偶发。修法：`setUp` 里 `_wait_for_editor_height()` 等编辑区
  拿到真实高度（最多 1 秒，等不到就明确报出来），裸 `next()` 换成带诊断的断言。
  **不是应用 bug**，是测试夹具对环境太敏感。
- 修完连跑两次全量 **378 项全绿**。
- 教训：**「这次不跑全量」要记账**，下次动代码时优先补跑。

## Windows 上截不到弹出菜单（踩了两次）

- `winfo_id()` 抓 Tk 菜单只有 1×1 —— 菜单是**原生窗口**，没有可抓的客户区。
  解法是从屏幕 DC 截：`tools/capture_window.py` 新增 `grab_screen_rect` / `capture_screen_rect`。
- 改完**脚本直接挂死**。逐段打标记（`tools/_probe_menu_post.py`）定位到最后一个标记是
  `before post`：**Windows 上 `menu.post()` 本身就不返回**（Tk 走原生 `TrackPopupMenu`，
  那是模态循环；`tk_popup` 同理还抢输入）。所以「先 post 再截图」根本走不通，
  主线程一进 post 就再也回不来。
- 修法：**先起后台线程**排好抓屏（睡 1.2s 等菜单画出来），**再进 `post()`**；
  线程抓完 `os._exit(0)`。抓屏是纯 ctypes GDI、不碰 Tk，所以子线程里调用安全。
- 一个进程只能摆一个菜单，所以主菜单与子菜单**分两次跑**：
  `python tools/_shot_doc_menu.py [sub]`（后来改的名）。
- 已写进 `~/.workbuddy-ai/skills/tk-text-incremental-highlight/references/tk-text-traps.md`
  与本项目 `MEMORY.md` 的「Tk 的硬约束」。

## 界面外壳一轮（用户一次提了六件事）

### 1. 导出长图 → 文稿右键菜单
- 顶栏的导出按钮撤掉；右键菜单顺序：打开 / 在资源管理器中显示 / **导出长图** / 移动到 / 删除文档。
- `export_long_image(path=None)`：**右键哪一篇就导出哪一篇**，不必先打开。
  `_export_source(path)` 分两种——是当前打开的那篇就用编辑区文本（含未保存改动），
  否则 `read_markdown` 从磁盘读。`_export_default_path(path)` 同理。`path=None` 仍指当前文档。

### 2. 导出后自动打开所在文件夹
- 写完盘调 `_reveal(written[0])`（`explorer /select,` → 打开并选中刚导出的图）。
  取消保存 / 导出失败都不打开。

### 3. 拼音预览字号 = 正文字号
- 输入法组字的字号归 Windows 管，**Tk 不同步控件字体**（Tcl 层 `info commands *ime*` 只有 `time`）。
- 只能自己调 imm32：`ImmGetContext` → `ImmSetCompositionFontW` → `ImmReleaseContext`，
  `lfHeight = -px(font_size)`，字族取 `_writing_font()`。改排版时 + 编辑区 `<FocusIn>` 各设一次。
- 字体计算抽成 `_ime_logfont()` 以便测试；整段 try/except，失败绝不打断打字。

### 4. 有序列表序号：永远蓝色、与正文同号
- 原来「光标不在该行」是画布画的 **11px** 蓝色小字，「光标在该行」变成灰色源码 → 会跳。
- 改成永远画布绘制：`_style_line` 里有序记号直接 `tag_add("syntax")`（**不走 `_tag_syntax`**，
  不记进 `_line_marks` → 光标进出不互换，永远 elide）；`_decoration_spec` 把 ordered 排除在
  「光标行不画装饰」之外；`_draw_decoration` 字号 `px(11)` → `px(settings["font_size"])`，
  画布宽度 `max(px(34), 字号*2)`。
- 项目符号/复选框**维持原样**，专门留了对比测试钉住。

### 5. 顶部栏自动隐藏（含「专注模式」）
- 鼠标进编辑区顶部 `px(46)` 窄带 → 滑出；离开 700ms → 收起。
- **必须用 `grid_remove()`/`grid()`**：只动高度不动宽度，正文不重新折行（有测试钉这个）。
- `<Motion>` 绑 toplevel（子控件冒泡上来），回调里只做整数比较；编辑区屏幕位置缓存
  `_panel_rect`，`<Configure>` 时失效。`topbar_hide_job` 加进 `_cancel_after_jobs`。

### 6. 编辑状态
- `正在编辑…` → `…`；`已保存` → 空。其它临时提示不动。
